## 📖 אודות המחקר

מאגר זה מרכז את כלל כלי המחקר, צינור עיבוד הנתונים, סקריפטי הסיווג מבוססי ה-LLM, לוחות התוצאות המנורמלים והאתר המחקרי המלווה את עבודת התזה בנושא מוסד הנשיאות לאורך הדורות בספרות חז״ל (התלמוד הבבלי והתלמוד הירושלמי).

המחקר מיישם את עקרונות ה-Digital Humanities ומתמודד עם הטיית הקורפוס (Corpus Bias) באמצעות מסגרת מתודולוגית ייחודית (Bias-Aware Framework), ניתוח כפול בסולם גולמי (0–3) ובסולם מנורמל (0–1.0), וניתוח השוואתי בין תקופה א' (עד רבי יהודה הנשיא) לתקופה ב' (רבי יהודה נשיאה ואילך).

## 🚀 הרצה מקומית של אתר המחקר

האתר הינו אפליקציית Web סטטית ועצמאית (Zero-Dependency), ואינו דורש תהליך בנייה (npm/webpack):

```bash
# הרצה באמצעות שרת ה-HTTP המובנה של פייתון
python3 -m http.server 8000 --directory thesis-website

# פתיחה בדפדפן
open http://localhost:8000
```
