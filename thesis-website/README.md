# אתר מחקר שושלת הנשיאים | מוסד הנשיאות בראי הניתוח הכמותי
## אתר מחקר מלווה לתזת מוסמך — פרק 8: "תמורות בתפקיד הנשיא: דפוסי מנהיגות בראי הניתוח הכמותי"

אתר אינטרנט מחקרי עצמאי וסטטי המיועד להרצה מקומית או לפריסה ישירה על גבי **GitHub Pages** (ללא שרת או צורך בתלויות חיצוניות).

---

## 🏛️ מבנה האתר (שלוש הלשוניות)

1. **לשונית 1: מתודולוגיה, רקע תיאורטי ופרומפטים (סעיפים 8.1–8.3 בתזה)**:
   - רקע במדעי הרוח הדיגיטליים (פרופ' חיים לפין, פרויקט 'דיקטה').
   - התמודדות עם הטיית הקורפוס (Corpus Bias) ומודל ה-Bias-Aware Framework.
   - צינור איסוף המקורות: ביאורי שטיינזלץ (בבלי) והרב מאיר כהן (ירושלמי), חלון 90 מילים, איחוד מופעים ומדגם תיקוף ידני של 10%.
   - סייר פרומפטים אינטראקטיבי: צפייה בנוסח המלא (Markdown) או בניתוח ההנחיות והעוגנים, עם כפתור העתקה בלחיצה אחת.

2. **לשונית 2: עיון במקורות וברשומות ההוכחה (סייר המקורות התלמודיים)**:
   - צפייה בכל 2,215 הקטעים שנותחו וסווגו על גבי קורפוס הבבלי והירושלמי.
   - בחירת נשיא לפי סדר כרונולוגי קפדני (7 נשיאים רשמיים + אפשרות להצגת קבוצות משלימות: הלל הזקן ור"ג המאוחר).
   - סינון לפי קורפוס (בבלי/ירושלמי), סדר (זרעים, מועד, נשים, נזיקין, קדשים, טהרות), וציר סמכות דומיננטי.
   - חיפוש חופשי בטקסט, במסכת ובנימוק המודל.
   - הצגת הטקסט בגופן **Frank Ruhl Libre** עם הדגשה חכמה של שמות בעלי מיליות יחס בעברית (ב, כ, ל, מ, ש, ו, ה) ומילות מפתח סמנטיות (תקנה, עבדים, שררה, קיסר וכו').
   - סולם ציונים כפול: גולמי (0–3) ומנורמל (0, 0.25, 0.5, 1.0) כולל פירוט פוליטי ואריסטוקרטי.
   - נימוק המודל (AI Reasoning) המצטט את הראיות מתוך הטקסט.
   - ניווט מהיר: דפדוף (הבא/הקודם), ניווט מקלדת (חצים ימינה/שמאלה), וקפיצה ישירה למספר קטע.

3. **לשונית 3: ממצאי המחקר, לוחות נתונים ותרשימים (סעיף 8.4 בתזה)**:
   - **כרטיסי הוכחה מרכזיים (Executive Proof Cards)**: הדגשת זינוק השררה פי 14.4, צניחת הסמכות התורנית, שתי התקופות ההיסטוריות ודומיננטיות הבבלי.
   - **תרשימים אינטראקטיביים רשמיים**:
     - גרף 1: התפלגות הסמכות האינטלקטואלית-תורנית.
     - גרף 2: התפלגות הסמכות המוסדית-חקיקתית.
     - גרף 3: הנהגה חיצונית-מעמדית ושררה.
     - גרף 4: קו פרשת המים — השוואת שתי התקופות (92.0% מול 29.6%).
     - גרף 5: תצוגה משולבת (100% Stacked Bar).
     - גרף 6: היפוך תפקידים (Scissors Effect: תורה מול שררה).
   - **לוח 8.4 הרשמי (ריכוז התוצאות המנורמלות)**: מיון עמודות בלחיצה על הכותרות, הצללת Heatmap עדינה לפי עוצמת המדד, מתג הצגת קבוצות משלימות (הלל הזקן - הערה 4), וכפתור ייצוא מלא ל-CSV.
   - **לוח 8.2 הרשמי (התפלגות לפי קורפוס)**: מיון עמודות, יחסי בבלי/ירושלמי, וייצוא CSV.
   - **כלי השוואה ראש-בראש (Generational Comparator)**:
     - חישוב פערי אחוזים בכל ציר סמכות.
     - תרשים עמודות מקובץ להשוואה ויזואלית ישירה.
     - שני כרטיסי קטעי הוכחה מייצגים מתוך התלמוד עם קישור ישיר לפתיחה בלשונית סייר המקורות.

## 🚀 הרצה מקומית (Local Preview)

האתר עושה שימוש במודולים עצמאיים (ES Modules), ללא צורך ב-build step (npm / webpack).
ניתן להריץ שרת מקומי פשוט:

```bash
# הרצה באמצעות פייתון מובנה:
python3 -m http.server 8000 --directory thesis-website

# פתיחה בדפדפן:
# http://localhost:8000
```

## 🌐 פריסה ב-GitHub Pages

1. דחוף את תוכן התיקייה `thesis-website/` לענף הראשי במאגר GitHub שלך (או צור ענף `gh-pages`).
2. בהגדרות המאגר ב-GitHub (Settings -> Pages):
   - בחר ב-**Deploy from a branch**.
   - בחר בתיקייה שבה שמורים הקבצים (או `/` אם הועלו ל-root של המאגר).
3. האתר יעלה לאוויר מיד תחת כתובת ה-URL של GitHub Pages.
